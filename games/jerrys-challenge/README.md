# Jerry’s Challenge

可爱像素风的双人合作横版解谜游戏。

当前试玩版 **0.7.4**：小家的床、椅子和沙发支持睡觉、坐下、站立和跳跃。靠近按 E / O 使用，W / ↑ 在家具上跳，左右或向下离开；R / 斜杠搬动，Q / Backspace 收纳。详见 [家具互动说明](../../docs/games/jerrys-challenge/家具互动.md)。

- 游戏工程标识：`jerrys-challenge`
- 技术选型：Godot 4.x 稳定版、GDScript、Compatibility 渲染器。
- [游戏设计文档](../../docs/games/jerrys-challenge/游戏概述.md)
- [第一关设计](../../docs/games/jerrys-challenge/第一关设计-一起去野餐.md)

当前版本：**0.7.3 可玩 demo**，Godot **4.7.2 stable**。

冰激凌两层颜色随订单水果变化：苹果红、草莓粉、橙子橙、香蕉黄、猕猴桃绿；加工完成和拿在手上使用同一口味配色，蛋筒不变。家具店第二页新增“餐椅”2 元，复用免费素材的四向绿色椅子，现共 15 种商品。

设置页可直接填写钱包金额（0–999999）并点“应用金额”，同步到小店和小家，不清空家具或订单。另有“打开存档目录”。正式进度仍在固定的 `user://` 目录，不随 `builds/版本号` 改变。

家庭存档采用临时文件校验后替换，保留 `.bak`、`.bak2`，并在每次启动首次保存前留一份 `backups/` 备份（最近 30 份）。读取主文件失败时回退有效备份。测试、截图和发布验证必须使用隔离存档；不要手动拿正式存档跑测试。

五种水果：苹果 1 元、草莓 2 元、橙子 3 元、香蕉 4 元、猕猴桃 5 元。顾客随机指定两种不同水果口味；按订单买对应水果，组合成本只显示 `1 + 2`、`3 + 5` 等加法式，不显示得数。结账反馈赚、亏或保本，不显示成本总数。

修复首次恢复时没有“下一位”：旧版本尚未进货的空订单改回报价阶段，能立即拒绝；已经付钱、搬运或加工的订单继续保留。

玩家名字可在“设置 → 玩家名字”或选人页“修改玩家名字”分别编辑，最多 8 个字，保存后用于角色头顶、关卡提示与小家；不再把左右键盘绑定为 Tom/Jerry。

冰激凌店先展示顾客随机出价（1–10 元）、两种水果口味和成本加法式，走到“接单”开始做，或去“下一位”拒绝。成交后才进货加工，交货时随机付款，再按成交价找零，结账显示赚/亏。详情见[顾客报价与交易](../../docs/games/jerrys-challenge/顾客报价与交易.md)。

家具店现有 14 种商品：保留椅子等免费家具，新增电视机、餐盘、餐具、水杯、电风扇、水壶。点右上角的独立鼠标按钮翻页；家具包也可翻页。餐具和水杯等可以放在桌面。

P2（方向键玩家）的互动统一为 **O**：选人准备、横版拾取和拉杆、俯视购买和搬放均用 O。↓ 在俯视中只负责向下移动。

房间家具支持直接放回库存：空手靠近高亮家具，P1 按 Q / P2 按 Backspace；手持时也可收纳。离开家具后按同一键打开家具包重新取出。钱和家具数量不变，自动保存。

标题“设置”里的“重置小家装饰（含库存全清空）”会删除房间、库存和手持的全部家具并保存，不退款；钱和小店订单保留。日常 Q / Backspace 收纳仍只是放回库存，不删除家具。

标题右上角有“设置”：无限金钱开关、增加 10 元、重置钱袋到 6 元。无限模式下水果和家具不扣普通余额，关闭后恢复正常余额规则；开关保存。重置钱袋保留家具和订单，清空未完成的付款盘。

**新增“我们的小家”**：从标题进入，或两人到冰激凌店楼梯右侧的“新家”小门互动进入俯视房间。房间底部左侧通家具店，右侧回冰激凌店。买家具使用与小店共用的钱，留 3 元进货金；可以打开家具包，拿出家具自由摆放、搬动和换现有朝向，布置自动保存。详见[小家说明](../../docs/games/jerrys-challenge/我们的小家.md)。

俯视操作：P1 用 WASD 移动、E 互动、R 换朝向、Q 家具包或收纳；P2 用方向键移动、O 互动、斜杠键换朝向、Backspace 家具包或收纳。进入俯视后 ↓ 只负责移动，回小店恢复原键位。家具包支持鼠标或左右选择后用互动键取出。

重新进入小店会恢复原订单、库存和钱，暂停菜单可重新集合。家庭存档为 `family_home.json`，保存小店经营与家具布置；旧小店存档首次读取时迁移，持有的家具退出后留在家具包。

家居使用免费 Pixel Lands Interiors Demo。原图受禁止再分发条款限制，不进 Git；开发机和本地构建已导入。其他电脑先从作者处下载免费包，再运行 `tools/asset-pipeline/import_home_assets.ps1` 并重新导入 Godot。缺图时使用占位，详见素材许可。

新增两个独立冒险，标题页选择后仍可选六种角色：

- **数字天平桥**：5、10、20 以内三档。天平一端放目标数，两侧共六张随机数字牌和加减号，保证有解。像拿苹果一样拿牌，放入三个凹槽拼成等于目标的算式，自动平衡开桥；两人一起走到最右侧刷新下一题。空手互动可拿回槽中的牌，持牌离开凹槽再互动可放回地面。不用点确认或拉杆。
- **冰激凌小铺**：先按顾客出价决定接不接，再到地下室付钱买苹果、莓果，回店从储物架搬到加工台。两人各站加工区一个金色脚印，同时按住 E / O 制作；完成后取货交给客人，再按实际成交价找零结账。

全程无订单倒计时、效率评分或顾客离场。小店有五种水果的十种双口味组合，顾客外观、配方、出价和付款随机；付款找零使用 1 元金币。钱包累计可能超过 10 元，单笔购买、支付、组合成本和找零练习都在十以内。材料商要求付正好，材料商找零和限时挑战尚未实现。

新冒险在互动后保存准确状态，包括零钱盘、手持物与库存；暂停可保存回标题继续。小店重新集合保留经营状态；天平桥重试保留本题，将所有牌放回原位。野餐仍使用独立的原有检查点存档。

已实现标题页、双人六角色选人、脚印教学、收集三个苹果、桥梁接力、各自点灯和野餐结尾。新增供家庭试玩的 Tom 小猫和 Jerry 小老鼠，默认分别预选这两个外观。支持暂停、提示、静音、当前小关重试、伙伴集合及按小关存档继续。主线无死亡与倒计时。

## 运行

优先双击仓库根目录 `builds/jerrys-challenge/0.7.3/JerrysChallenge.exe`，或运行根目录 `启动游戏.ps1`。发布包与引擎工具保留本地，不提交 Git。

开发时，用 Godot 4.7.2 导入本目录 `project.godot` 后按 F6/F5 运行，或使用根目录 `启动游戏.ps1`。无需安装 .NET。

| 玩家 | 移动 | 跳跃 | 拾取 / 放下 / 使用机关 |
| --- | --- | --- | --- |
| P1 | A / D | W | E |
| P2 | ← / → | ↑ | O |

选人页：左右切换，互动键准备；双方准备后，再按任一互动键出发。也可用鼠标操作选人按钮。允许两人选择同一个外观，用 P1/P2、名字和不同标记区分。

Esc 暂停，F1 显示/隐藏提示。水果门和野餐灯的双拉杆需要两人同时按住 E 与 O，保持 1.8 秒，直到总开关锁定。任一人提前松手、离开拉杆或跳起，拉杆就会回弹，总开关进度清零。花朵桥仍采用按一次的接力规则。退出后“继续上次的冒险”会从当前小关起点恢复，不保留关内临时状态。

```powershell
# Safe regression checks: each test gets an isolated profile automatically.
.\tools\run_checks.ps1
# Local release export (does not start the game or alter play progress).
& .tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path games/jerrys-challenge --export-release 'Windows Desktop'
```

## 当前边界

- 已加入 Tom 与 Jerry 的家庭试玩同人外观。家庭成员定制外观、女孩角色、可编辑键位及截图按钮尚未实现。

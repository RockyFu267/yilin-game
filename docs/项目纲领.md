# Yilin Game 项目纲领

记录日期：2026-10-23。本文记录创作者背景、明确需求与设计方向，作为后续设计和开发的长期上下文。

## 创作者与家庭背景

- 创作者 RockyFu267 是资深游戏爱好者，对游戏品味与品质有很高要求。
- 认可的优秀游戏包括《巫师 3》《荒野大镖客 2》，平时较少玩 2D 游戏。
- 目前有一位 6 岁的女儿，希望亲自为她制作游戏，并与她一起游玩。
- 项目计划持续制作一系列寓教于乐的完整游戏，认真对待玩法、内容、美术和体验品质。

## 核心愿望

本文是系列共用背景。具体游戏的角色、关卡、技术选型及进度各自记录在 `docs/games/<游戏标识>/`；游戏工程位于 `games/<游戏标识>/`。首款游戏为 [Jerry’s Challenge](games/jerrys-challenge/游戏概述.md)。

首款游戏也要支持孩子和邻居小朋友一起玩；游戏内两位玩家身份为 Tom 和 Jerry，不固定为爸爸与女儿。亲子情感目标保留为创作背景，不强制所有玩家具有亲子关系。

制作一款具有《双人成行》那种共同冒险与合作过关体验的 2D 横版游戏，让它成为爸爸和女儿一起快乐的情感枢纽。

孩子应当能感受到：这是属于我们家的冒险，我和爸爸都很重要，我们一起想办法、互相帮助、共同完成了挑战。

## 已明确的需求

1. **游戏形态**：2D 横版，以双人合作过关为核心。
2. **共同游玩**：爸爸和女儿在同一台电脑上共用一个键盘游玩。
3. **美术方向**：可爱、亲切的像素风格，以仓库中的 `Pixel Adventure 1.zip` 为具体风格参考。
4. **素材复用**：尽可能复用适合的现有素材，并沿同一风格扩展新的美术元素。
5. **家庭角色**：需要能设计女儿、爸爸、妈妈的像素角色，让孩子感到熟悉、亲切。三位家庭角色不等于首期必须支持三人同时游玩；妈妈在游戏中的具体角色待定。
6. **挑战方向**：以观察、解谜、合作、推理、算术等思考活动为主，目的是锻炼智力。
7. **操作方向**：避免将快速反应、精准操作或魂类游戏式的高惩罚挑战作为核心。
8. **情感目的**：共同快乐和亲子关系是最重要的目标，学习内容应服务于有趣的共同冒险。

## 设计解释与建议（需要通过原型验证）

以下是基于上述需求的设计建议，并非用户已确认的具体机制：

- 将品质要求落实到世界氛围、角色表现、关卡变化、操作反馈和完整体验；开发规模逐步增长。
- 借鉴《双人成行》中双方能力互补、共同解决问题和机制持续变化的设计。
- 让孩子拥有独立判断和帮助爸爸的机会，避免爸爸解题、孩子只跟随。
- 给玩家充足的思考时间；优先采用低惩罚失败、就近重试、可等待的机关。
- 算术可融入分配水果、平衡重量、搭桥等具体情境。题目范围与提示程度根据孩子实际体验调整。
- 家庭角色除外形外，还可通过熟悉的动作、称呼、物件与互动建立亲切感。
- 共用键盘需要尽早验证同时按键冲突、左右手布局与孩子手掌跨度。

## 素材初步检查

已实际查看压缩包中的欢迎图、地形图与 Virtual Guy 待机动画：

- 地形图文件标注为 16×16 图块；主要角色动画文件标注为 32×32 帧。
- 风格明快、可爱，角色轮廓清楚，使用块面与少量明暗塑造体积。
- 包含角色、地形、背景、水果、箱子、检查点、陷阱及菜单素材，可作为原型素材基础。
- 家庭角色需要在相近像素密度、比例、轮廓、色彩和动画表现下另外设计；尚未制作，也尚未获取家庭成员的具体外观参考。
- 后续核对已确认 Pixel Adventure 1 作者发布页采用 CC0，详见[素材索引目录](../素材索引目录.md)。

## 素材复用原则（2026-10-23 补充）

- 复用素材优先选择完全免费、授权明确的资源，并确认允许游戏使用、修改及商业发行，避免后续发行需要补购许可。
- 首选 CC0；允许免费商用但要求署名的资源也可作为候选，保留许可并落实署名要求。
- 免费样本、Demo 仅使用其明确授权的免费部分，不依赖付费完整版。
- 仅个人非商业免费、商用需付费，以及免费部分授权不清楚的素材，暂不整合进正式游戏资源。
- 当前优先以 Pixel Adventure 1 建立横版原型与画风基础。新增付费素材不默认采购或使用。

## 后续设计的判断标准

评估一个新机制时，优先回答：孩子是否能理解并参与？双方是否都有贡献？是否会自然产生交流、帮助与共同成就？失败后是否仍愿意一起再试？它是否让这段亲子时光更快乐？

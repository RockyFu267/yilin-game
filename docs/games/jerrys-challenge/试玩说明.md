# Jerry’s Challenge · 0.3.0 试玩说明

双击 `builds/jerrys-challenge/0.3.0/JerrysChallenge.exe`，不需要安装 Godot。

## 怎么开始

1. 点击“开始一起冒险”。
2. 两人各选一个角色，可以选相同的。Tom用 A/D 切换、E 准备；Jerry 用左右方向键切换、下方向键准备。也可用鼠标点击。
3. 两人准备好后，再按 E 或下方向键出发。

| 玩家 | 左右移动 | 跳跃 | 拾取 / 放下 / 机关 |
| --- | --- | --- | --- |
| Tom | A / D | W | E |
| Jerry | ← / → | ↑ | ↓ |

Esc 暂停，F1 提示。任何时候都可以慢慢想，没有倒计时。

## 关卡提示

建议先让孩子观察与尝试，需要时再看下面：

1. **家门口**：每人站上一个脚印，门开后两人一起走到最右边进门。
2. **三个苹果**：走近苹果按互动键拿起；带到篮子旁再按互动放入。凑齐三个以后，Tom 在左侧拉杆旁按住 E，Jerry 在右侧拉杆旁按住 ↓。两人同时保持约两秒，让总开关锁定，再一起走到最右边。
3. **花朵小桥**：一人转左边的木柄，另一人走到中间花岛按互动，替伙伴打开后半段路。接力机关必须由不同玩家完成。
4. **我们的野餐**：Tom 在左侧拉杆旁按住 E，Jerry 在右侧拉杆旁按住 ↓。任何一人松开、走远或跳起都会让自己的拉杆回弹、总进度清零。两人同时保持 1.8 秒，直到总开关锁定，才能松手；之后一起到野餐垫，各按互动坐下。

离开后可从标题页“继续上次的冒险”恢复到当前小关起点。暂停菜单可以重试当前小关，或让两人重新集合到安全位置。

## 这版的范围

这是可完整通关的合作原型：六种伙伴可选，包含新增的 Tom 小猫与 Jerry 小老鼠同人像素外观，两位玩家都能选择。保留简洁的粗颗粒天空与树木、木质像素 UI 和同时保持型合作机关。首次游玩时长尚未经孩子实测，不保证此前设计目标中的 8–12 分钟。

已进行脚本逻辑、模拟双人输入、桥梁物理碰撞、独立 EXE 完整流程检查，并查看实际渲染画面。实际键盘的同时按键冲突和孩子的操作难度，仍需要你们真人试玩验证。

试玩时请特别留意：孩子在哪里笑了，在哪里不知道该做什么，是否主动说“让我来”。这些比完成得快更有价值。

# 家具互动试玩版 · 0.7.4

赚到钱买回家的床和椅子，可以用来玩耍。适用于所有可选角色。

| 操作 | 左边玩家 | 右边玩家 |
| --- | --- | --- |
| 上床站好，再按切换睡觉／起床 | E | O |
| 坐到椅子，再按切换站立／坐下 | E | O |
| 在家具上跳；睡觉时先起床再跳 | W | ↑ |
| 离开家具 | A、D、S | ←、→、↓ |
| 搬起床或椅子；搬着时换朝向 | R | / |
| 收回库存，空地打开家具包 | Q | Backspace |

床、原有小椅子、新餐椅和沙发都支持互动。一件家具一次由一个角色使用，伙伴使用时不能搬动或收纳。两人可以各自在不同家具上玩。互动不花钱，不改变家具的购买和摆放存档，退出房间后姿势重置。

第一版复用角色已有的站立、跳跃和头像素材；坐姿用压低身体的方式表现，睡觉叠加像素被子、轻微呼吸和 Zzz。后续可补专用坐姿和闭眼头像，提高动作自然度。

俯视角中 W／↑ 原本用于向上走：只有使用家具时改为跳跃，离开家具后恢复向上移动。

# Jerry’s Challenge · 角色与选人

## 目标

两位玩家都可以选择自己的冒险伙伴，默认身份为 Tom（P1）和 Jerry（P2），不绑定爸爸、妈妈或孩子。支持亲子搭档，也支持孩子与邻居小朋友搭档。女孩可以选小动物、面具角色或其他喜欢的形象；可爱女孩也应是候选方向。名字不锁定特定皮肤。

## 选人流程

1. 标题页进入选人界面，左右两张玩家卡，同时展示预览、名字和按键。
2. Tom（P1）A/D 切换、E 确认；Jerry（P2）←/→ 切换、↓ 确认。
3. 双方确认后显示“出发吧”，由确认键启动第一关。允许取消确认后重新选择。
4. 允许选同一外观，用 P1/P2 图标、名字和不同形状的头顶标识区分，不能只靠颜色。
5. 外观不改变速度、跳跃和机关权限，不让孩子为了通关被迫放弃喜欢的形象。

0.3.0 默认给 P1 预选 Tom 小猫，P2 预选 Jerry 小老鼠，但不锁定选择。原四套 CC0 外观保留；新增角色的制作记录见 [Tom 与 Jerry 角色制作](Tom与Jerry角色制作.md)。游玩中保留名字和玩家标识。

## 女孩与小动物扩展

- 本地 PixelSerial 免费样本有女性俯视角角色，但没有确认完整横版动作，且有 AI 内容平台限制，不作为当前直接替换或生成输入。
- 本地 SuperRetroWorld 含人物造型，但为俯视角且存在较宽 AI 项目限制，不作为首期角色依赖。
- 可爱女孩角色尚未确认合适的完全免费横版素材。筛选时要求明确允许商用和修改，并检查待机、跑动、跳跃、落地及互动动作是否齐全。
- 可用自有外观参考设计原创女孩、原创小鼠和家庭角色。原创小鼠采用独立配色、服饰与轮廓，避免直接复制《猫和老鼠》Jerry 的具体设计。
- [Kenney Pixel Platformer](https://kenney.nl/assets/pixel-platformer) 已核对为免费 CC0、18×18 图块，可作扩充候选；未下载、未确认其中有符合要求的小女孩，不列作已可用角色。

0.2.0 已实现四种免费角色独立选择、双方确认及同外观区分。新增外观不阻塞合作关卡。

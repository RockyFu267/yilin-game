# Jerry’s Challenge

中文工作名：Jerry 的挑战。英文名：**Jerry’s Challenge**。工程标识：`jerrys-challenge`。

## 游戏定位

一款可爱像素风的双人合作横版解谜游戏，两位玩家共用一个键盘，一起观察、商量、互相帮助并完成冒险。玩家身份为 Tom（P1）和 Jerry（P2），可以由家长和孩子搭档，也可以由孩子和邻居小朋友搭档，不绑定家庭关系。首个 demo 为[第一关：一起去野餐](第一关设计-一起去野餐.md)，目标在 2026-10-24 进行首次试玩，实际交付状态以可运行构建为准。

## 已确认的角色偏好

孩子是女孩，喜欢扮演《猫和老鼠》里的 Jerry。她可以自主选择喜欢的角色；角色选择不按性别限定。0.3.0 按用户希望满足孩子小愿望的要求，为家庭试玩加入 Tom 与 Jerry 的同人像素外观，保留其辨识特征，并适配本作像素比例。

两位玩家都能选角色。保留四套免费现成角色，新增 Tom 与 Jerry，共六种；可爱女孩、其他小动物和家庭定制角色继续保留为扩展方向。

## 当前实施决定

- 引擎：Godot 4.x 稳定版。
- 语言：GDScript。
- 渲染器：Compatibility。
- 首个目标平台：Windows 本地双人，同一键盘，同屏。
- 角色外观与玩家输入、关卡能力分离。双方核心能力一致，任何角色都能完整过关。
- 复用素材遵循系列的完全免费优先原则，当前首选 Pixel Adventure 1（CC0）。

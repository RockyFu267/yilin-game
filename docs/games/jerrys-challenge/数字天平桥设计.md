# Jerry’s Challenge · 数字天平桥

0.4.1 按 Rocky 的新规则重写，替代“小鸭排队与天平桥”。本次只改天平关，小店流程待单独讨论和修改。

## 一题怎么玩

天平左端固定一个目标数字，例如 6。场地左侧三张数字牌、右侧三张数字牌，共六张；场景只保留一张加号和一张减号。数字允许重复，但每张都是独立物品，不能把同一张牌用两次。

Tom 与 Jerry 自由分工，像搬苹果一样走近牌，按 E / O 拾取，每人最多拿一张。把牌搬到天平下方的三个凹槽：`数字 | + 或 − | 数字`。右托盘同步呈现算式。

例如选择 `8 − 2` 或 `2 + 4`，都能与左端的 6 平衡。六张数字不必全部使用；第一版只拼两个数的加减，不做连算、乘除、括号或把两张单位数字拼成多位数。20 以内模式中 `12` 是一整张牌。

放错时空手靠近凹槽，互动拿回其中的牌；拿着另一张牌时不能直接覆盖已有牌。中间只能放符号，两边只能放数字。离开凹槽再互动，会把手中牌放回地面，伙伴可以拾取。无需选项窗口、提交按钮、拉杆或计时。

完整算式结果不等于目标时，天平向较重一侧倾斜；不完整时目标端下沉。结果相等即自动平衡并打开右侧通道。两位玩家一起走过右侧出口，刷新下一题；不要求再次按键，也不让一位玩家提前刷新伙伴的题目。新题的全部牌重置，双方回到左侧起点。

## 随机题保证有解

5、10、20 以内三档由标题选择，先用十以内试玩。每题目标数在 2 到当前上限之间，数字牌值在 1 到上限之间。

生成器先选目标与一种可行运算：

- 加法：构造正整数 `a + b = 目标`。
- 减法：构造范围内的正整数 `a − b = 目标`；目标等于上限时用加法，避免引入范围外的被减数。

将这两个数字加入候选，再生成四张干扰数字，打乱位置。加减号均可取得，玩家不必使用生成器预设的解，任何合法的两个不同实体数字牌组成的等式都能过关。不会生成无解题，也不把提示答案写在界面里。

允许试错，没有扣分或时间限制。算式可出现算错后的负值或超出上限的值，天平仅显示比较反馈；生成器保证的正确解仍在当前数值范围内。

## 状态与验收

每张牌只有地面、某位玩家手中或某个凹槽三种位置之一。存档保存目标、六张数字、符号、牌的位置、双方手持、当前题号和完成状态。暂停重试只把本题所有牌放回原处，不改题；旧版排队存档无法转换成题目时，进入一题新的数字天平。

自动检查覆盖三档各 400 道随机题的可解性、数字范围与独立牌约束；同时覆盖抢同一牌、错误槽位、落地再拾取、错误算式不通行、加减两种正确解自动开门、双人通过后刷新、暂停、重试及存档。实际视觉和键盘手感通过导出包截图与试玩继续检查。

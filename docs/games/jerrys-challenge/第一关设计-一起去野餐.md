# Jerry’s Challenge · 第一关：一起去野餐

设计日期：2026-10-23。目标试玩日：2026-10-24（周六）。

## 这一关要带来的感受

Tom 和 Jerry 一起穿过小花园，收好水果、修好小桥，最后坐到野餐垫上。两位玩家各有发现答案和帮助伙伴的机会。参与者可以是家长和孩子，也可以是两个小朋友。过关后，玩家想说的是“我们再来一次”。

这是一个可以完整通关的双人合作 demo。首次游玩目标约 8–12 分钟，实际时长需试玩验证。

## 开场与美术

游戏标题：“Jerry’s Challenge”。选人后进入第一关“一起去野餐”。默认玩家显示名为“Tom”和“Jerry”，与选择的角色外观独立。

开场一句话：“野餐篮准备好了！我们一起把水果带到小花园吧。”

采用 Pixel Adventure 1 的免费 CC0 地形、水果、检查点与按钮，做明亮草地、柔和背景、木箱和水果。第一版提供四套现成角色供双方选择，不把Tom或孩子固定为某个外观。头顶始终显示玩家名字与 P1/P2 标识；详见[角色与选人](角色与选人.md)。可爱女孩、原创小动物及家庭定制人物后续扩充。

不把宣传图中的敌人当作已有动画；本关无需敌人、尖刺、生命值或战斗素材。

## 键盘与基本规则

| 玩家 | 移动 | 跳跃 | 互动 |
| --- | --- | --- | --- |
| Tom（键盘左侧） | A / D | W | E |
| 孩子（键盘右侧） | ← / → | ↑ | O |

- 默认无双跳、无冲刺。主线谜题可在平地完成；小跳台只用于开场练习和可选探索。
- 走近机关时出现按键提示。拾取和花朵桥使用单次互动；水果门和野餐灯的拉杆必须由两位玩家持续同时按住，直到场景中的总开关锁定。松手、走开或跳起均会使未完成的操作回弹。
- 角色互不阻挡，不会把对方推下平台。
- 使用同屏镜头；机关房间尽量整屏可见。过渡处等双方到齐再移动到下一段，快走者不会把另一个人带出屏幕。
- Esc 暂停，R 在暂停菜单中提供“重试当前小关”。进度在每段结束时自动记录，退出后可继续。
- 键位可调整。首轮技术验证先检查“双方移动/跳跃 + 互动”的同时按键情况；机关设计避免依赖多键长按。

## 路线

家门口（认识角色与操作） → 水果门（数量） → 花朵桥（互相帮助） → 野餐灯（合作创造） → 野餐结尾。

每段约 1–3 分钟。教学以图示和场景反馈为主；短句可以由Tom读给孩子听。

### 0 · 家门口：先一起动起来

安全平地，旁边有一块可跳上的矮木箱。两人可以各自走动，熟悉自己的角色与按键。

出口是两个足够宽的脚印区域；两人分别站入后，门缓缓打开并保持开启。地面用图标提示“两个脚印，都有人啦”。没有倒计时，不要求同时踩入。

**验证**：孩子能辨认自己的角色；Tom能等待，不会因为先走就把孩子落下。

### 1 · 水果门：一起装满三个位置

门旁显示一个野餐篮和三个空的水果位置，场地左侧有一个苹果，右侧有两个苹果。

- 每人最多携带一个苹果，走近按互动拾取；篮子旁按互动放入。
- Tom的起始路线经过一个苹果，孩子的路线经过两个苹果，但允许自由分工。
- 放入后，对应空位变成清楚的实心苹果，显示当前数量“1 / 3”“2 / 3”“3 / 3”。
- 篮子满后，两人各到自己的拉杆旁，Tom 按住 E、Jerry 按住 O，同时保持 1.8 秒才能锁定总开关并开门。提前松手会清空未完成的进度。
- 提示先显示三个空位；停留较久后增加“还差几个苹果？”；Tom可手动开启更明确提示。

**学习机会**：实物计数、数量对应与“1 和 2 合起来是 3”。不弹考试窗口，不因答错扣分。孩子可以先数，Tom再按孩子的计划行动。

**防卡住**：掉落苹果可重新拾取；进入新段前自动清理携带状态。谜题完成后不撤销。

### 2 · 花朵桥：这次换我来帮你

花丛旁有两条平行路径，中间是浅浅的小溪；桥由两段组成。水只是可站立的浅水区，误入后从附近缓坡走回。

1. 起点旁有一个大木柄。Tom走近，按互动转动它，第一段桥永久放下。
2. 孩子沿第一段桥走到中间的小花岛。岛上有一个花朵机关，Tom在起点还能看见她。
3. 孩子按互动让花朵绽放，第二段桥永久放下，并同时打开Tom路线的花藤门。
4. 两人在出口碰面，出现短句：“刚才你帮我，现在我帮你！”

机关不锁定外观；提示引导一位玩家先操作、另一位接力，便于两位伙伴交换帮助者的身份。两段桥不回弹，不要求抢时间，也不需要跨越宽坑。

**学习机会**：先后顺序、因果关系、轮流行动。孩子的贡献要在画面上清楚可见。

### 3 · 野餐灯：两个人一起让花园亮起来

野餐垫旁有两根拉杆，各自连接自己的灯串与中央总开关。Tom 站在左侧按住 E，Jerry 在右侧按住 O，才能保持拉杆下压和线路通电。

一人先拉时只点亮自己的线路，总开关不动；松手、走开或跳起就回弹熄灭。两人必须同时保持 1.8 秒，让总开关逐渐下压并锁定；任何一方提前松开都会清零。锁定后双方可以松手，再一起去野餐垫坐下。这里不要求快速反应或同一瞬间按下，玩家可以慢慢商量。

这一段提供轻松的情绪收束，不再加入更难的数字题。若孩子愿意，可在旁边安全的小平台捡额外水果；额外收集不影响通关。

### 结尾 · 属于我们家的野餐

两人走到野餐垫，各按一次互动坐下。镜头固定，篮子出现三颗苹果，播放轻柔庆祝动效。

结尾文案：

> 今天我们一起装满了野餐篮，也一起修好了小桥。
> 谢谢你陪我冒险！

最后显示大字：“Tom 和 Jerry，一起完成！”提供“再玩一次”和“留在花园”两个按钮；不显示通关时间排名、不比较双方贡献。截图纪念仍是后续可选功能。

## 试玩难度与帮助

- 主线无死亡惩罚、无限时、无失败扣分。掉出地图边界时回到当前小段安全位置，不重置已完成机关。
- 文字短、大且易读，重要内容同时用图标表达。不能只凭颜色识别机关。
- 提示分为环境闪光、图示提醒和明确操作说明，逐步出现；暂停菜单可手动打开提示。
- 家长辅助可以把落后的角色带回最近安全地点，保留孩子继续操作的权利。
- 音效有开关；尚无确认授权的音频时，先用程序合成简短提示音或保持静音，视觉反馈必须完整。

## 首个可玩版本的交付边界

**必须有**：双角色同键盘操作、双方可选角色、三个合作段落、安全重试、开场和结尾、清楚提示、可重新开始、已确认免费素材，以及双击即可启动的试玩入口。

**可后补**：家庭定制角色、妈妈角色、配音、更丰富音效、额外收集物和截图按钮。核心优先保证两个人能顺利操作、明白要做什么、完整过关。

暂不加入联网、账号、复杂物理、角色成长系统、战斗和大量关卡。

引擎选用 Godot 4.x 稳定版、GDScript 与 Compatibility 渲染器，详见[技术方案](技术方案.md)。当前命令行未找到 Godot，实施前确认安装位置与导出模板。优先提供 Windows 独立试玩包与简短操作说明。

## 试玩验收

1. 两个人真实共用一个键盘，验证双方同时移动、跳跃、互动，发现冲突就调整默认键位。
2. 首次游玩的孩子能认出自己的角色；各关提示能在近处读到，画面没有被另一玩家带走。
3. Tom停下来时，孩子有可自己完成的操作和能被看见的贡献。
4. 随意丢水果、反向走、先到出口、掉出边界、重复按机关，都不会卡死。
5. 完成一次从开始到结尾的双人通关，重新开始不会保留错误状态。
6. 关闭后重新启动，在目标电脑上可玩；素材和字体齐全，不依赖开发机的绝对路径。

试玩后重点记录：孩子在哪儿笑了、在哪儿不知道该做什么、Tom是否说得太多、孩子是否主动说“让我来”。据此调整第二版。

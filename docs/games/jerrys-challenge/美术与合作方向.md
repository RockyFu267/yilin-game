# Jerry’s Challenge · 美术与合作方向

更新日期：2026-10-23，当前版本 0.2.1。

## 0.2.1 · 以现有角色为风格标尺

用户指出 0.2.0 的高细节森林插画与角色不统一。当前改为按 3 倍像素网格直接绘制背景，接近原地形的像素尺度：简洁蓝天、阶梯状云、有限树叶色阶、块面树干和低对比远景，地面复用原草地与泥土图块。

核心判断标准是角色、地形、背景能否像同一套美术，而非背景单独是否精美。后续扩充仍以 Pixel Adventure 的角色轮廓、像素密度和配色复杂度为准。0.2.0 的森林图不再用于游戏渲染，也不包含在新版导出包；文件与生成提示词仅作为历史尝试保留。

## 用户反馈形成的要求

- 画面应具备游戏美术审美。树、蓝天、提示和按钮不能继续沿用系统应用的圆角卡片与扁平几何风格。
- 借鉴《泰拉瑞亚》等像素游戏中世界、材质、场景物件和 UI 的整体感，使用原创与许可明确的素材，不复制原作具体资产。
- 合作必须产生实时依赖。两人先后各按一次机关，不能代替两人同时保持操作。

## 0.2.0 的历史实现

- 原创像素森林背景：树冠、树皮、远山、云层、光束和草地形成层次。
- 使用木质标牌、铜色边框、像素铆钉和有厚度的按钮；英文标题采用 Silkscreen 像素字体，中文系统字体关闭平滑并加描边。
- 地形、门、房屋、花朵、拉杆、篮子和灯笼统一采用像素块面。场景附近才出现互动提示，远处用小标记吸引观察。
- 保留玩家头顶名字和两个角落的简短操作提示，便于小朋友认识自己的角色。
- 苹果继续位于角色前景层。

## 同时保持型机关

水果门的双拉杆和野餐灯的双拉杆采用同一规则：

1. Tom 站在自己的拉杆附近按住 E，Jerry 在另一根旁按住 ↓。
2. 单人按住只让自己的拉杆下压、线路通电，总开关不推进。
3. 任意一方松手、离开有效距离或跳起，自己的拉杆回弹，总开关未完成的进度清零。
4. 两人同时持续保持 1.8 秒，场景中的总开关逐渐被拉下并锁定。
5. 锁定后才允许双方松手并继续前进。暂停会清除尚未锁定的操作状态。

这段保持时间用于让玩家看见彼此配合的结果，无倒计时、无抢拍或精准同时按下要求。

花朵桥暂时保留“先开路、另一人接力”的不同合作机制，避免每个谜题都变成相同的双拉杆；后续关卡继续检查双方是否真正互相依赖。

## 0.4.0 实现边界

提供 5、10、20 以内三档，标题由陪玩者选择，不自动升级。每档先用三只鸭熟悉排队，再分别使用 3→5、6→10、12→20 的加法及反向减法，最后补足对应目标完成双人天平桥。支持重复搬动、送回和准确存档，所有操作无计时压力。

当前小鸭显示在等候、队伍和池塘的图示区域，邀请后由角色头顶的手持鸭表示，交付时直接加入对应区，尚未实现独立跟随走路。互动台支持拿取与交付；确认是单人操作，两人合作集中在搬运和最终双拉杆。天平为单位重量示意图，左盘以一只鸭图标代表队伍、数量另行标注，尚非逐只登上物理乘台。最终桥是完成反馈，未加入真实河坑或船班动画。

自动检查覆盖三档完整加减搬运、超额调整、双人保持和释放回弹。逐只点数高亮、独立小鸭行走、五格/十格布局的进一步美术打磨、完整渡河演出是后续工作，不能以原始设计描述代替已交付功能。

## 目标与学习依据

Tom 和 Jerry 帮小鸭参加河对岸的野餐。两位玩家共用键盘，在安全的河岸上带小鸭排队、接送伙伴，最终让天平桥放平。

孩子目前会借助手指数数。本关允许她继续这样做，也允许在屏幕上逐只点数；不以脱离手指、心算速度或首次答对为目标。

参考美国教育科学研究所的学前数学教学指南及其配套工具包：从孩子已有能力出发，递进学习数与运算；用物体、手指、图画、五格框等表示数量，实际演示集合的合并与分离。NAEYC 的数的组成教学文章也介绍了在游戏、故事与小数量操作中理解数的组合。

- [IES / WWC：Teaching Math to Young Children](https://ies.ed.gov/ncee/WWC/PracticeGuide/18)
- [IES：Teaching Math to Young Children Toolkit](https://ies.ed.gov/ncee/rel/math-young-children)，重点参考 Meaningful Counting 和 Solving Basic Problems。
- [NAEYC：Playing Around with Number Composition](https://www.naeyc.org/resources/pubs/tyc/spring2022/number-composition)

以下机制是基于这些原则的游戏设计推演，不是上述机构验证过的游戏课程；没有承诺训练效果。具体数量、时长和提示阈值由家庭试玩调整，不把六岁等同于统一水平。

| 学习原则 | 关卡中的具体体现 |
| --- | --- |
| 一一对应 | 一个脚印位置站一只鸭；点数时一次只突出一只 |
| 数到最后得到总数 | 点完后整队一起轻轻回应，再显示“共 3 只”；不只播放数词 |
| 操作数量变化 | 新来的鸭从等候区走进队尾；离开的鸭走到可见池塘 |
| 看见部分与整体 | 原有三只与新来两只保持空间分组，合起来仍是五只 |
| 由具体情境连接符号 | 先经历事件，再可选展开对应算式，算式不作为操作入口 |
| 按表现提供支持 | 需要时保留五个空位和逐只点数；熟悉后可隐藏部分辅助 |

## 场景和操作

一屏一段，无危险跳跃、倒计时、死亡或分数。木栅栏、脚印、小鸭和天平都采用当前游戏粗像素风；提示放在场景木牌上，不弹计算题窗口。颜色之外还用队伍位置、鸭子形态或分组间隔表达关系。

沿用移动、跳跃与互动键：P1 A/D/W/E，P2 方向键/上/下。靠近小鸭单次互动邀请跟随，每人最多带一只；再次互动可让它停下。靠近队尾脚印互动加入，靠近队中小鸭互动可邀请离队。脚印自动补紧队尾空位，不要求玩家精确对齐像素。

被另一玩家带领或正在行走的小鸭不可重复拾取。短按只执行一次动作，避免一次按键同时带走又放下。玩家停下时小鸭等待，不会自动越过出入口。小鸭走到位置后才更新队伍人数，行走中可看见目标位置，但不能提前过关。

## 第一段：找到自己的位置

目标：先观察孩子能否把小鸭与位置一一对应，不考加减。

河岸有三个带鸭脚印的等候位置，两只鸭已经站好，旁边一只在找位置。木牌画出三只鸭，不预先要求识别数字 3。

一位玩家去邀请落单小鸭，另一位单次互动打开小木门。木门保持打开，小鸭入队后双方可在木牌旁点数。点数通过单次互动逐只高亮，不自动跳到答案，也没有节奏要求；最后一次突出整队并显示总数。允许不点数直接共同确认出发。

两人各在出口脚印上单次确认后继续，先确认的状态保留，队伍变化才撤销确认。门的操作和带领可以交换，不按 Tom/Jerry 锁定职责。

## 第二段：又来了两只（3＋2）

三个已入队的小鸭等待，另外两只从树后探头。排队区域有五个位置，原队伍占前三个，后两个空着。

提示：“还有两位朋友，一起带过来吧。”两位玩家可以各带一只，商量后分别从两侧接送；每只入队都保留独立行走过程。新来的两只停在队尾，用短暂的动作和分组间隔帮助看出“原来三只”和“新来两只”，不永久依赖颜色区分。

队伍完整后，玩家可逐只点数，也可直接共同确认。确认后全队庆祝，木牌显示五只鸭的图示和总数；可展开 `3＋2＝5`，其中两部分图示与场上分组对应。不会要求选择数字 5 才能开门。

合作：两人各自完成一次接送可以更快，但允许一位玩家代劳，避免操作困难卡关；不把参与次数当成奖励指标。计数时伙伴可以等待、协助开门或按孩子建议移动小鸭。

## 第三段：两只去游泳（5－2）

同样五只鸭排队，旁边池塘画有两个游泳位置。提示：“两位朋友想先去游泳，送它们到池塘吧。”任意两只都可以，不要求认特定鸭子。

两人各邀请一只，把它带到池塘。入水的小鸭仍在画面里，剩下三只继续排队；原有五个脚印保留，可看到三个占用、两个空位。不要把小鸭直接删除或变成红叉。

送多了，可以再请回来；送少了，空的池塘位置自然提示还需要一位。对“现在队里还有几只”可点数或商量，不强迫口头作答，也不自动语音报出结果。两人共同确认后显示数量变化，算式 `5－2＝3` 仍是可选回顾。

本段目标明确是“送两只到池塘”，不是要求所有场景小鸭变成三只。验收分别检查队伍 3、池塘 2，防止混淆总数与子集。

## 第四段：还差几只，才能过桥？（3＋□＝5）

三只鸭来到桥头，岸边另有三只可邀请的鸭。木牌展示五只鸭图案，桥头等候区容量六只，常规辅助显示五个目标位置及一个额外位置，让“放多”也能被看到和修正。

提示：“这班渡桥要五位小伙伴，现在还差几位？”不先说“再找两只”。玩家可以数空位、用手指，也可以邀请鸭子后再观察。放到六只时不惩罚，额外位置上的小鸭轻轻挥手，玩家能邀请它返回岸边等候区。

### 天平的数学关系

桥是一台等臂天平：一边为小鸭乘坐的升降台，另一边是固定的五个单位配重。设定中所有小鸭都重一个单位，每个配重也重一个单位；明确用相同的单位图案说明。两位玩家站在独立岸边操作台，**不参与称重**。

只有左侧小鸭数量恰好为 5 时两边等重，桥才能对齐。此处是“五个单位等于五个单位”，不是把两边重量相加到五。美术不能画成不同体型的小鸭却仍默认为等重。

准备队伍时天平锁定在安全位置；玩家可以打开预览机关，缓慢展示当前偏向，数字不直接报出还差几只。左侧较轻时左台上升，较重时下沉；少、正好、多都能恢复并继续调整，无小鸭掉落。

### 两人的实际合作

小鸭都登台、双方共同确认后，一人到左侧释放锁扣，另一人到右侧操作绞盘。沿用现有关卡的同时保持机制：两边持续互动 1.8 秒，且重量正确，桥缓慢对齐并锁定。放手、离开或跳起使未完成的动作回弹；不会清空已经排好的队伍。

重量不对时保持键不会开始计时，机关只展示天平倾斜和可调整的队伍。计数、商量和搬鸭期间无需任何人长按；只有确定出发才合作操纵桥。锁定后两人松手，一起跟小鸭过桥。也可在无障碍辅助中改为两侧分别单次确认，保留双人参与。

已完成后不再撤回队伍或重新称重。最后几只岸边鸭会由下一班接送，故事说明它们没有被遗弃。

## 提示与陪玩方式

默认显示实物和目标脚印。玩家主动在提示木牌互动，依次获得：突出目标区域 → 图示比较队伍和空位 → 演示邀请一只或送回一只。每次只前进一步，不自动替玩家解完整题。

静止等待不能直接判为不会，可能正在数手指或商量。只有长时间没有改变场景时让提示木牌轻微闪动，不自动加难或揭晓答案。第一版由陪玩者在暂停菜单选择“更多辅助 / 常规”，不根据通关速度自动升级。

陪玩可问：“你准备怎么试？”“你想让我带哪只？”“我们看看还空几个位置。”孩子从头数或掰手指都接受；如果她主动从三继续数四、五，可以跟随，不要求改用更快方法。不连续追问，不把每次操作变成口试。

如果显得疲倦，任意段完成后都能存进度退出。首轮尝试约 8–12 分钟，只是设计预算，不是表现标准；也可以当天只玩加法接送。

## 首版范围与状态检查

只做 5 以内、固定四段流程，不随机出题，不实现十以内进位、复杂物理或评分。五个位置是一行的“五格”视觉辅助，尚不把它宣传为十格教学。以后扩展十以内时采用两行五格，并另行试玩。

新增状态：每只鸭唯一 ID、归属区（等候/队伍/池塘/乘台）、带领者、行走目标；每段目标、双方确认、天平锁定状态。所有状态改变按小鸭唯一 ID 执行，重试当前段应恢复该段初始状态；退出重新进入不重复生成鸭子。

实现验收：

1. 计数对应场上实际到位的小鸭，不能把路上、池塘或其他玩家带领的鸭重复计入。
2. 两人同时抢同一只、反复按互动、先离开、带鸭跳跃、先确认再改队伍，都不卡死。
3. 3＋2 的五只、5－2 的队伍三只和池塘两只、补足五只均有可见过程；算式与真实变化一致。
4. 三只或六只都不能锁桥，五只可完成；天平倾斜方向正确，玩家体重不影响结果。
5. 总开关前松手会回弹，已完成排队不会重置；锁桥后状态永久保持。
6. 不识字也能跟随主要图示；数字、颜色都不是唯一线索；全程可慢慢操作。

家庭试玩观察：孩子能否自己邀请一只鸭、是否一只对应一个数词、是否愿意调整、是否主动告诉伙伴如何帮忙。另换一个小数量如 2＋1 时是否还能操作，可作为后续设计参考；通关本身不能证明已经掌握加减法。只记简短体验，不收集儿童画像或公开表现排名。

这是一个为女儿制作一系列寓教于乐游戏的项目。

希望她能在探索世界、解决难题和经历冒险的过程中，收获快乐、好奇心与成长，也留下属于我们共同的回忆。

## 项目愿景

我们要做的是有完整体验、值得反复游玩的真正游戏：有自己的世界、角色、玩法与成长过程，并持续打磨内容和品质。

寓教于乐是游戏设计的一部分。知识与思考会自然融入探索、互动和挑战，让孩子在游玩中发现、尝试和理解。

## 从像素风格的 2D 横版游戏开始

系列的第一步将从 **2D 横版游戏** 开始，采用 **像素美术风格**。

- **探索与冒险**：通过移动、跳跃和场景互动，逐步认识游戏世界。
- **挑战与成长**：用有趣的关卡和循序渐进的挑战，鼓励观察、思考与尝试。
- **学习融入玩法**：让学习内容成为解决问题和推进冒险的自然组成部分。
- **完整的游戏体验**：重视操作手感、关卡设计、美术、音效与故事表达。

## 开发理念

- **好玩是基础**：先让孩子愿意玩、喜欢玩，再让学习在游玩中发生。
- **尊重孩子的好奇心**：鼓励主动探索，给尝试和犯错留出空间。
- **认真打磨每一款游戏**：以完整游戏项目的标准设计、开发与迭代。
- **从小范围做起，逐步拓展**：先打磨核心玩法，再丰富关卡、内容和世界。
